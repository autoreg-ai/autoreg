# Autoreg Documentation

Autoreg is an **AI test regression agent** that automates manual and repetitive test workflows.

Use this docs site to go from zero to a running Autoreg setup.

## What you can do with Autoreg

- Orchestrate regression testing across environments
- Trigger workflows from CI/CD pipelines
- Standardize flaky-test triage and reporting
