# Installation

## 1. Download AutoReg

Grab the installer for your OS from the download page:

**[https://autoreg-ai.vercel.app/download](https://autoreg-ai.vercel.app/download)**

| OS | Installer |
|----|-----------|
| macOS (Apple Silicon & Intel) | `AutoReg.dmg` — open and drag AutoReg to Applications |
| Windows 10+ | `AutoReg Setup.exe` — run the installer and follow the prompts |

## 2. Choose your AI model (optional)

AutoReg works out of the box with the default model. You can switch models any time via the chat composer — no restart needed:

| Mode | Notes |
|------|-------|
| **Auto** | Default — fast and cheap |
| `gpt-5.5` | Most capable |
| `gpt-5.4-mini` | Balanced |

More model providers are coming soon.

## 3. Install the spec-generator extension

The **AutoReg: Skill Installer** extension for VS Code (and VS Code-compatible editors) installs the `generate-autoreg` AI skill into your coding agent — Claude Code, Cursor, GitHub Copilot, Windsurf, Cline, and more. The skill analyzes your app's source code and writes a complete, signed `autoreg.md` spec automatically, so you don't have to write one by hand.

1. In VS Code, open **Extensions** and search for **AutoReg: Skill Installer** (publisher: `autoreg`).
2. Open the **AutoReg** panel in the activity bar.
3. Click **Install** next to the coding agents detected in your workspace.

Full walkthrough: [Generating autoreg.md](/guide/generate-spec).

## Log files

All app output is written to a rotating log file — useful when reporting issues:

| OS | Path |
|----|------|
| Windows | `%APPDATA%\AutoReg\logs\autoregDDMMYYYY.log` |
| Mac | `~/Library/Logs/AutoReg/autoregDDMMYYYY.log` |

Max 100 MB per file; archived with `_N` suffix on rotation.
