# Quick Reference

## Setup

1. Download the installer for your OS: [autoreg.sh/download](https://autoreg.sh/download)
2. Launch AutoReg
3. Install the **AutoReg: Skill Installer** VS Code extension to [auto-generate your spec](/guide/generate-spec)

## Keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New Workflow |

## Agent chat prompts

### Generation
```
"Generate tests for my workflow at /path/to/workflow"
"Regenerate all tests"
"Regenerate scenario-005"
"Add a test for the export CSV button"
```

### Execution
```
"Run all tests"
"Run scenario-003"
"Stop tests"
```

### Analysis & healing
```
"Fix the failing tests"
"Heal scenario-007"
"Why is scenario-004 failing?"
"Analyze the last run"
```

### Defects (feedback loop with your coding agent)
```
"File a defect for my coding agent"   ← offered after an app-defect diagnosis
"What bugs are open?"
"Verify fixes"
"Did my agent fix DEF-0003?"
```

### Editing
```
"Add a test scenario for password reset"
"Update scenario-002 to use the new modal selector"
"Delete scenario-011"
"Organize the plan into sections"
```

### Inspection
```
"What scenarios were generated?"
"Take a snapshot of https://myapp.example.com/dashboard"
"Show me the plan"
```

## Workflow folder layout

```
<app source>/.autoreg/ui/
├── autoreg.md           ← your spec (required for generation)
├── myworkflow.ar         ← manifest (auto-managed)
├── tests/
│   └── scenario-NNN.json
├── plans/
│   └── e2e-plan.json
├── runs/
│   └── 2026-06-23T14-32/
│       ├── execution.log
│       ├── diagnostics.json   ← console/network errors the app produced
│       └── artifacts/
├── baseline.json           ← spec baseline (delta mode)
├── defects/                ← defects AutoReg filed for your coding agent
└── fixes/                  ← your coding agent's fix reports
```

The workflow lives under your app source at `.autoreg/ui/` or `.autoreg/api/`. Your coding agent can find defects there directly; Reggie also shows each defect path.

## Generating `autoreg.md` from source code

In your AI coding agent (after installing the [skill](/guide/generate-spec)):

```
/generate-autoreg /path/to/autoreg-workflow /path/to/app/src
```

## Headless CLI

```
npx @autoreg/cli run ./workflow --all       # or: Settings → Command line → Install, then `autoreg …`
```

For setup, test parameters, and a complete pipeline example, see [Run AutoReg from the CLI and CI](/guide/cli).

## Fixing a defect AutoReg filed (in your coding agent)

```
/fix-autoreg-defect "C:/…/my-app/.autoreg/ui/defects/DEF-0003.json"
```

Run it without arguments and it asks for the path Reggie showed you.

## JSON Step DSL — quick action reference

```json
{ "action": "navigate",   "value": "https://..." }
{ "action": "click",      "selector": "[aria-label='Submit']" }
{ "action": "fill",       "selector": "[aria-label='Email']",  "value": "user@test.com" }
{ "action": "select",     "selector": "#country",              "value": "US" }
{ "action": "hover",      "selector": ".menu-trigger" }
{ "action": "press",      "selector": "[aria-label='Search']", "value": "Enter" }
{ "action": "scroll",     "selector": "#footer" }
{ "action": "assert",     "selector": "text=Welcome",          "assertionType": "visible" }
{ "action": "assert",     "selector": ".toast",                "assertionType": "contains", "expected": "Saved" }
{ "action": "wait",       "selector": ".spinner",              "assertionType": "hidden", "timeout": 3000 }
{ "action": "evaluate",   "value": "window.scrollTo(0, 0)" }
{ "action": "screenshot"  }
```

**`assertionType`:** `visible` (default) · `hidden`/`not_visible`/`not_exists` · `exists` · `equals` · `contains`
