# Quickstart

This project uses a standard **Next.js + Nextra** docs stack.

## Prerequisites

- Node.js 20+
- npm 10+
- GitHub repository access

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. In Vercel, click **Add New Project** and import the repository.
3. Keep default settings:
   - Framework: **Next.js**
   - Build Command: `npm run build`
   - Output: default
4. Click **Deploy**.

Your docs site will be live on a Vercel URL after the first build.
