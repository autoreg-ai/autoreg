# Getting Started

This guide helps you bootstrap technical docs and prepare your team for Autoreg adoption.

## Prerequisites

- Node.js 20+
- npm 10+
- Git

## 1) Install dependencies

```bash
npm install
```

## 2) Run docs locally

```bash
npm run dev
```

Visit `http://localhost:3000`.

## 3) Build for production

```bash
npm run build
npm run start
```

## 4) Deploy docs to Vercel

- Connect repository in Vercel.
- Use default Next.js settings.
- Deploy.
