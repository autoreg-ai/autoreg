# Autoreg

Autoreg is an **AI test regression agent** that automates end-to-end and integration test workflows.

Use this documentation to:

- Understand what Autoreg does.
- Set up your environment quickly.
- Run your first automated regression flow.

## Why Autoreg

- Reduces manual regression effort.
- Helps keep release quality high.
- Scales with your existing test stack and CI workflows.
